## Overview

This is a research project focused on understanding how user profiling shapes what people see online. 

This includes:
- Ads
- Recommendations
- Platform content distribution
- Broader narrative and information exposure

The goal is to study how targeting work in practice, and eventually simulate different user profiles to observe how online platforms respond.
